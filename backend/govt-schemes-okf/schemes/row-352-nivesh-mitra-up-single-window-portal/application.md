## Process

1. Visit the Nivesh Mitra portal at https://niveshmitra.up.nic.in
2. Register on the portal using personal and contact details
3. Receive user ID and password via SMS/email
4. Log in to the portal using the credentials
5. Fill the Common Application Form and create a Unit
6. Select the desired department and service (e.g., Change of Land Use, MSME registration)
7. Attach required documents as specified for the service
8. Submit the application form online
9. Pay the applicable fee online via the payment gateway
10. Track application status using the grievance redressal or status tracking section
11. Receive digital approval/NOC upon successful processing
12. Download the certificate from the online system

## Deadlines

- Rolling basis — no fixed deadline. Applications are accepted year-round.
