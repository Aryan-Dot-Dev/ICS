## Process

1. Register on the Startup Haryana portal at https://startupharyana.gov.in.
2. Log in using email/password, Gmail, or Startup India login details.
3. Select 'Startup' as the registration type.
4. Ensure DPIIT recognition is obtained prior to application (if not, get recognized via DPIIT first).
5. Complete the 4-step application form: (a) Details of the entity (Startup Details, Authorized Representative Details, Incubation Details, Upload Documents), (b) Details of Directors/Designated Partners, (c) Details of Business, (d) Preview and Final Submit.
6. Upload all required documents (file size ≤ 2 MB).
7. Accept terms and conditions and submit the application.
8. Application is processed within 30 days if no deficiencies; if deficiencies are found, applicant has 10 days to resubmit.
9. Upon approval, download the registration certificate from 'My Applications' section.

## Deadlines

- Rolling basis — no fixed deadline. Applications are accepted year-round.
