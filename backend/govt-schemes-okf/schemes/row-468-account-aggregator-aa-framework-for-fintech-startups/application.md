## Process

1. Get registered with a Financial Service Regulator (RBI, SEBI, IRDAI, PFRDA, or GSTN).
2. Implement the required module (FIP/FIU/AA/TSP) using RBI-defined API specifications published by ReBIT.
3. Test the module in RBI-approved Account Aggregator Sandboxes.
4. Enrol the module in the UAT-Central Registry for testing in the development environment.
5. Obtain certification from a Sahamati-empanelled auditor for adherence to ReBIT Technical Standards.
6. Get details publicised by Sahamati in the Central Registry upon going live.
7. Launch services with customers.

## Deadlines

- Rolling basis — no fixed deadline. Applications are accepted year-round.
