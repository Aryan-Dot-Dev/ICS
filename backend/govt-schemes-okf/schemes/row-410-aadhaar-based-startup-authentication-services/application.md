## Process

1. Visit the UIDAI developer portal at https://uidai.gov.in/section/developer-portal
2. Register as an Authentication User Agency (AUA) or Sub-AUA
3. Submit required documentation including legal entity proof and security compliance
4. Upon approval, obtain API access credentials
5. Integrate Aadhaar authentication APIs into your startup's platform
6. Begin conducting Aadhaar-based e-KYC and authentication transactions.

## Deadlines

- Rolling basis — applications are accepted throughout the year.
