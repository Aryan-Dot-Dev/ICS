## Process

1. Open https://ahidf.udyamimitra.in/
2. Enter mobile number of Applicant. Select the checkbox of “I am not a Robot” and click on “Request OTP” button.
3. Enter 6 digits OTP received on Applicants mobile number and click on ‘Verify OTP’ button. Upon verification of OTP, User will be successfully on boarded.
4. Fill Applicant information, Promoters/ Management details and Project Information.
5. Validate all required fields on Fill Application tab and save/ Submit application.
6. On Successful submission on Application details, User will navigate to Upload Documents Page. On this screen user need to upload Project Documents and Documents related to Applicant/ Promoters.
7. Submit Application to marketplace or submit application to preferred lender.
8. Click on Submit to check Application Status and Application No.
9. View application status. Once application submitted, Application status become Logged. User can view application details or download application from this screen. In case of Application withdrawal click on Withdraw button so that application will get Withdraw and User need to apply again.
