## Process

1. Register on the Startup India portal (startupindia.gov.in)
2. Obtain DPIIT recognition via the 'Get Recognised' section
3. Navigate to the Innovation Week Challenge or specific program page
4. Fill out the application form with startup details and innovation description
5. Upload required documents such as incorporation certificate, PAN, and pitch deck
6. Submit the application and await evaluation
7. If selected, participate in the challenge events and receive benefits

## Deadlines

- Rolling basis — applications are accepted year-round for various challenges under Startup India Programs.
