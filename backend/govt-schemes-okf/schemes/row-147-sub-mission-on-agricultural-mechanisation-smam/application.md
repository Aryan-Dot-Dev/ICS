## Process

1. Visit https://agrimachinery.nic.in and click on 'Registration' from the navigation bar.
2. Select beneficiary type: Farmer, Entrepreneur, Society/SHG/FPO, or Manufacturer.
3. Enter required details: For Farmer – Aadhaar/mobile/name, state, district, block, village, land area, address, pincode, bank details, and identity proof; for Entrepreneur/Society – GSTN/PAN, contact details, address; for Manufacturer – GST certificate, product details, test report, bank details.
4. Accept terms and conditions and submit to receive User ID and password (sent via SMS).
5. Login to the portal using credentials.
6. For machinery purchase: Select implement, check availability, add application, generate PIN, select dealer, negotiate price, upload bill and joint photographs.
7. For CHC project: Apply for CHC establishment, upload project details (agriculture graduate, domicile, DOB certificate), await government officer approval, print permit, upload implement bill and loan documents (if applicable).
8. After physical verification by government officer, subsidy is approved and payment file generated for disbursement.
9. Track application status via Application Tracking system using reference number.

## Deadlines

- Rolling basis — applications are accepted throughout the year as per state-specific timelines and Annual Action Plan (Demand) submission to M&T Division.
