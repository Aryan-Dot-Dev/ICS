## Process

1. Visit the PM CARES Fund website (pmcares.gov.in)
2. Select the mode of donation (Net Banking, Card Payments, UPI, NEFT/RTGS, Cheque/DD, etc.)
3. Complete the transaction through the chosen channel
4. Go to the 'Print Receipt' section on the website
5. Select the channel used for donation
6. Enter mobile number and bank reference number
7. Enter Transaction Order Number/Merchant Order Number or Bank Reference Number
8. Click on Get OTP and enter the OTP received on mobile
9. Click on Submit to download the receipt

## Deadlines

- Rolling basis — no fixed deadline. Donations are accepted year-round.
