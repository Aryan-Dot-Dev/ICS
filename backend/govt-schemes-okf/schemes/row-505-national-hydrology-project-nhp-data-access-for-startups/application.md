## Process

1. Visit the National Hydrology Project official website at https://nhp.gov.in
2. Navigate to the data access or startup engagement section
3. Review the data access policy and terms of use
4. Submit a request for data access detailing the startup's purpose and intended use
5. Await review and approval from the NHP data access committee
6. Upon approval, receive credentials or access links to the requested datasets

## Deadlines

- Rolling basis — no fixed deadline. Applications for data access are accepted throughout the year.
