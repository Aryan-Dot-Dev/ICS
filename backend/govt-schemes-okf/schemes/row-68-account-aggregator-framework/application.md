## Process

1. Get registered and regulated by at least one Financial Service Regulator (RBI, SEBI, IRDAI, PFRDA).
2. Implement the required module (FIP, FIU, or AA) using RBI-defined API specifications published by ReBIT.
3. Test the module in RBI-approved Account Aggregator Sandboxes.
4. Enrol the module in the UAT-Central Registry for testing in the development environment.
5. Obtain certification from a Sahamati-empanelled auditor for adherence to ReBIT Technical Standards.
6. Get details publicised in the Central Registry upon going live.
7. Launch services with customers.
8. For Regulated Entity (RE) membership in Sahamati: submit valid registration certificate, executed Membership Terms, authorization document, and proof of certification; pay applicable annual fee based on entity category.

## Deadlines

- Rolling basis — no fixed deadline. Applications are accepted year-round.
