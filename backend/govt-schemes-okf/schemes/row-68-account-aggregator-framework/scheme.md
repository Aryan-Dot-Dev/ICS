# Account Aggregator Framework

## Overview

The Account Aggregator (AA) framework is an RBI-approved initiative under India's Digital Public Infrastructure that enables secure, consent-driven sharing of financial data between Financial Information Providers (FIPs) and Financial Information Users (FIUs) via Account Aggregators (AAs). It empowers individuals and businesses to access financial services like loans, insurance, and wealth management by providing real-time, verified financial data with explicit user consent. The framework promotes financial inclusion, reduces operational friction, and supports innovation across lending, investments, insurance, and personal finance sectors. Sahamati acts as the industry body driving adoption, setting standards, and enabling interoperability within the AA ecosystem.

## Objective

- Enable secure, consent-driven sharing of financial data across financial institutions
- Promote financial inclusion by expanding access to credit for underserved and first-time borrowers
- Improve efficiency in lending, insurance, and wealth management through real-time data access
- Strengthen fraud mitigation and operational efficiency for financial service providers
- Support innovation in financial products and services using aggregated financial insights
- Ensure data privacy and user control over personal financial information
- Establish standardized protocols and fair use templates for responsible data usage
- Drive adoption of Account Aggregator ecosystem as a foundational pillar of India's Digital Public Infrastructure

## Important Conditions

- Account Aggregators cannot store, process, or sell customer data
- Data sharing is only possible with explicit user consent
- Only asset-based data (bank accounts, deposits, mutual funds, insurance, pension funds) is currently accessible
- Entities must obtain certification to ensure interoperability and adherence to ReBIT standards
- RE membership in Sahamati requires being 'Live' or 'Ready to go Live' in the AA production environment
- All NBFC-AAs are classified under Fee Category B for Sahamati membership
- Certain entities like AD-II, CRA, PoP, Research Analyst, AIF, TReDS, Cooperative Bank, Depository, PPI Issuer, RRB, and AIFIs are classified under Fee Category C
- Token refresh API migration deadlines apply (e.g., old Token APIs discontinued effective 21st August 2025)
- V1 API endpoint URLs in Central Registry were deprecated and required migration to V2 by 30th June 2024
- RRB amalgamation effective 15th September 2025 requires CR updates: transferor RRBs to be deleted, transferees to update names
- Sahamati SahAAyak portal undergoes scheduled downtime for upgrades (e.g., May 18th, 2026, 5:00 PM–10:00 PM IST)
- Fair Use Template implementation rules are updated periodically;
