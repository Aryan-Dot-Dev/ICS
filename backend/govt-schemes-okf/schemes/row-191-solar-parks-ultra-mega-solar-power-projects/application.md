## Process

1. State Government designates an implementing agency for the solar park.
2. The implementing agency prepares the Detailed Project Report (DPR) and applies for a grant of up to Rs. 25 Lakh from SECI for DPR preparation.
3. Upon DPR approval, the implementing agency applies to SECI for the main project grant of up to Rs. 20 lakhs/MW or 30% of the project cost (including grid-connectivity), whichever is lower.
4. SECI appraises the application and sanctions the grant.
5. Grant is released by SECI in installments linked to project milestones.
6. SECI monitors the project progress and ensures compliance with scheme guidelines.
