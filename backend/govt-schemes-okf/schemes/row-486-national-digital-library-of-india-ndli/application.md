## Process

1. Visit the NDLI portal at https://ndl.iitkgp.ac.in
2. Browse or search for resources using the search bar or explore by subject, language, or resource type
3. For institutional registration, set up an NDLI-Club via https://club.ndl.iitkgp.ac.in to obtain an Institutional Registration No.
4. Individual users can register for an account via https://ndl.iitkgp.ac.in/account/registration
5. Use the portal to access learning materials, prepare for exams, or conduct research without any fees.

## Deadlines

- Rolling basis — no fixed deadline. Access and registration are available year-round.
