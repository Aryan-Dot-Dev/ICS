## Process

1. For eSign ASP onboarding:
2. Submit application form to ESP.
3. Submit supporting documents for KYC.
4. Accept terms of eSign service.
5. Submit Digital Signature Certificate (public key).
6. Integrate API in testing/preproduction environment.
7. Conduct audit and submit report.
8. Obtain readiness confirmation and Go-Live approval.
9. Obtain production access certificate. For general use: developers can access APIs via sandbox environments provided by intermediaries like Digio, Karza, Signzy, or OnGrid.
