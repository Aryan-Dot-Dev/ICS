## Process

1. Identify the project and prepare a detailed project report including technical, financial, and economic aspects.
2. Ensure compliance with eligibility criteria, including women entrepreneurship status and Udyam registration.
3. Approach the nearest SIDBI branch or authorized channel with the project report and required documents.
4. Submit the application along with KYC documents, business registration proof, and financial statements.
5. SIDBI conducts technical and financial appraisal of the project.
6. Upon approval, loan sanction is communicated, and disbursement is made in stages as per project progress.
7. Complete documentation and create security as per loan terms.
8. Begin repayment as per the agreed schedule after moratorium, if any.
