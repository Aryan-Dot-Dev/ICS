## Process

1. Visit the MahaDBT portal at https://mahadbt.maharashtra.gov.in.
2. Register as a new applicant using mobile number, Aadhaar, PAN, and scholarship/application ID if applicable.
3. Log in to the portal using credentials.
4. Browse or search for eligible schemes under departments like Skill Development, Employment and Entrepreneurship, or others.
5. Select the desired scheme and click 'Apply'.
6. Fill in the application form with personal, educational, and financial details.
7. Upload required documents such as domicile, caste, income, educational certificates, and Aadhaar.
8. Submit the application and note the application ID.
9. Track application status in real time via the portal.
10. Upon approval, benefits are transferred directly to the Aadhaar-seeded bank account.

## Deadlines

- Application acceptance for the new academic year A.Y. 2025–26 has commenced from 30th June 2025. Application acceptance (Fresh/Renewal) for A.Y. 2025–26 will continue until 30th June 2026. The Re-apply provision for A.Y. 2023–24 and A.Y. 2024–25 will continue until 30th June 2026.
