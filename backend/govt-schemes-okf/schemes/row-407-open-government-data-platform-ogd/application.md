## Process

1. Visit the OGD Platform at https://data.gov.in
2. Browse or search for datasets using keywords, sectors, or tags
3. Select a dataset to view its metadata, preview, and download options
4. Click 'Download' to access the dataset in preferred format (CSV, JSON, XML, etc.)
5. Optionally, register for personalized features such as saving favorites or tracking updates
6. Developers can access APIs via the developer section for programmatic data retrieval.

## Deadlines

- Rolling basis — no fixed deadline. Data is published and accessible continuously as it is released by government sources.
