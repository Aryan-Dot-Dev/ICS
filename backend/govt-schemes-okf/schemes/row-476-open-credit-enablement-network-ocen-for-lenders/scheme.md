# Open Credit Enablement Network (OCEN) for Lenders

## Overview

Open Credit Enablement Network (OCEN) is a framework of application programming interfaces (APIs) designed to democratize credit access for MSMEs by enabling interaction between lenders, loan agents, collections and disbursement partners, derived data providers, and account aggregators. It aims to solve the MSME credit gap of ₹20-25 trillion by facilitating short-tenure, small-ticket loans through standardized, consent-based data sharing and specialized participant roles. OCEN 4.0 introduces product and participant registries maintained by SROs, enabling a cambrian explosion of customized cash-flow based lending products across sectors.

## Objective

- Create a framework for short tenures & small ticket loans
- Allow remote lenders to operate in distant geographies
- Enable consented access of alternate sources of data
- Reduce the burden on lenders through specialized participant roles
- Increase credit accessibility in underprivileged areas
- Enable discovery and collaboration via product networks
- Standardize APIs for minimal integration effort
- Ensure security via OAuth 2.0, OpenID Connect, and digital signatures

## Important Conditions

- OCEN is a framework, not a lending entity — it does not sanction or disburse loans directly
- Participant roles and responsibilities must be clearly defined within Product Networks
- Data sharing requires explicit borrower consent under consent-based flow models
- Dispute resolution relies on SRO mediation;
- effectiveness depends on SRO capacity
- API integration requires technical compliance with security and idempotency standards
- Loan terms (amount, tenure, interest) are set by lenders, not OCEN
- Success depends on network effects — sufficient participation of lenders, Loan Agents, and partners
