## Process

1. Register on the Startup India portal.
2. Apply for DPIIT recognition via the National Single Window System (NSWS).
3. After obtaining DPIIT recognition, access the Section 80 IAC exemption application form on the Startup India portal.
4. Fill in all required details and upload the necessary documents.
5. Submit the application form for review.
6. Track application status via the dashboard on the Startup India Portal.

## Deadlines

- Rolling basis — no fixed deadline. Applications are accepted year-round.
